# Rstack project

## Setup

Install the dependencies:

```bash
pnpm install
```

## Scripts

- `pnpm run build`: Build the app for production.
- `pnpm run check`: Run static checks, including lint and format.
- `pnpm run dev`: Run the app dev server.
- `pnpm run format`: Format code.
- `pnpm run lint`: Lint code.
- `pnpm run preview`: Preview the app production build.
- `pnpm run test`: Run tests.
- `pnpm run test:watch`: Run tests in watch mode.
